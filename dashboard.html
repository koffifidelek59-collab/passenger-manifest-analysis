Interpretation

Survived ↔ Sex / Class: strongest structural links with survival.

Fare ↔ Class: negative correlation with Pclass (1st class = higher fare).

Age: weak linear link with survival; age bands matter more than raw age.

Use correlation as a guide, not a causal claim. Confirm with stratified rates.

Insights & Recommendations

Key Recommendations

  • Prioritize Sex, Class, and Fare in predictive models.
  • Handle missing Cabin carefully · use a CabinKnown flag, do not impute.
  • Engineer Family Size as a categorical feature (Alone / Small / Large).
  • Review Fare outliers before modelling (log transform or winsorize).
  • Collect more complete cabin and age data for future manifests.

Scientific notes

Survival differences by sex and class are large and consistent with historical accounts of evacuation priority.

Cabin missingness is not random: first-class records are far more complete. Treating missingness as a feature preserves information.

All KPIs use the cleaned train set (n = 891). Age means shown in Overview use the pre-imputation distribution for transparency.

About

Project scope

EDA of the Titanic manifest · Python only (Pandas, Plotly) · no Excel / Power BI / Tableau.

Dataset

Kaggle Titanic training set · 891 passengers, 12 source columns. Genuine survival labels. Cleaned file: manifest_clean.csv.

Cleaning decisions

  • Age: median by Title × Class
  • Cabin: not imputed (informative missingness)
  • Embarked: mode for 2 missing rows
  • Features: FamilySize, Alone, Deck, AgeBand

Deliverables

  • Python analysis script
  • Cleaned dataset
  • Interactive dashboard
  • Documented KPIs and insights
